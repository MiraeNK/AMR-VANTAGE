# FMR VANTAGE — Logo concept 02
Tanggal: 8 November 2026.
Status: konsep revisi lambang; belum diterapkan ke aplikasi.

## Revisi
Lambang lama berbentuk percabangan jalur diganti menjadi monogram geometris F/M yang kompak.
Dua bentuk bersudut membentuk satu identitas, dipisahkan celah diagonal.
Wordmark FMR VANTAGE, bentuk huruf, kemiringan, ukuran, posisi, dan warnanya dipertahankan dari concept 01.
